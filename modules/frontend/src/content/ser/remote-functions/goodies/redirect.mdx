---
title: "Redirect"
description: "Redirect requests from Effect handlers with SvelteKit control flow."
---

> [!NOTE] Since 2.3.0
> The `external` option requires `svelte-effect-runtime` 3.4.3 and SvelteKit 3.

`ts Redirect` wraps SvelteKit's `ts redirect` helper as an Effect. Like
`ts Error`, the returned Effect never succeeds — SvelteKit takes over the
request and issues the redirect.

## Redirect a request

```ts name="save.remote.ts" icon="ts"
import { Command, Redirect } from "svelte-effect-runtime";
import { Effect, Schema } from "effect";

export const SaveDraft = Command(DraftSchema, (draft) =>
	Effect.gen(function* () {
		yield* DraftRepository.save(draft);

		return yield* Redirect("SeeOther", "/drafts");
	}),
);
```

The status accepts a number or a PascalCase status name, so
`ts Redirect(303, ...)` and `ts Redirect("SeeOther", ...)` are equivalent. The
location may be a string or a `ts URL`.

## Redirect to external URLs

SvelteKit 3 requires opting in before redirecting outside the app. Pass
`external: true`, or an allowlist of origins:

```ts name="checkout.remote.ts" icon="ts"
return yield* Redirect("TemporaryRedirect", payment_url, {
	external: ["https://checkout.example.com"],
});
```
